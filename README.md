## 🧠 My Engineering Philosophy

- **Automate repetitive work:** If a task is performed repeatedly, look for a safe and maintainable way to automate it.
- **Infrastructure should be reproducible:** Prefer version-controlled, reviewable, and repeatable infrastructure changes.
- **Security belongs in the workflow:** Build security checks into the development and delivery lifecycle instead of treating them as an afterthought.
- **Least privilege by default:** Grant access according to workload requirements and minimize unnecessary permissions.
- **Observe before reacting:** Use metrics, logs, alerts, and system evidence to diagnose issues rather than relying on assumptions.
- **Design for failure:** Consider recovery, failure scenarios, and operational behavior when designing systems.
- **Keep solutions practical:** Favor maintainable automation and measurable improvements over unnecessary complexity.
- **Share knowledge:** Document solutions, improve workflows, and help make complex technology easier to operate.
